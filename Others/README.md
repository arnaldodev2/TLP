🎯 Purpose

This repository contains assignments, exercises, projects, and study materials developed throughout the TLP (Programming Languages Techniques) course as part of my Software Development studies.

The goal is to strengthen programming knowledge, develop logical thinking, and learn how to solve problems through algorithms and practical solutions.

📂 Repository Structure

Folder / File| Description
📁 "C-Programming/"| Exercises and projects developed in C.
📁 "Fluxogramas/"| Flowcharts and visual representations of algorithms.
📄 "README.md"| Main repository documentation.

🛠️ Technologies and Tools

- C — learning programming fundamentals.
- Flowcharts — representing algorithms visually.
- Git — version control.
- GitHub — hosting and sharing projects.
- Markdown — documenting content.

📈 Learning Objectives

- Develop logical and algorithmic thinking.
- Understand variables, data types, and operators.
- Work with conditional statements and loops.
- Create and use functions.
- Learn about arrays, pointers, and data structures.
- Learn to organize, test, and document programs.
- Use Git and GitHub to track project development.

🚀 Progress

This repository will be updated as new topics, exercises, and projects are developed.

The goal is to document my learning journey, from programming fundamentals to solving more complex problems.
